As relações do BD são as seguintes:

* Um para Um: 1 Aluno -> 1 GRR

* Um para Muitos: 1 Aluno -> n Disciplina

* Muitos para Muitos: n Disciplinas -> n Departamentos

Com base nas relações acima, temos as seguintes tabelas:

* Aluno
* GRR
* Departamento
* Disciplinas
